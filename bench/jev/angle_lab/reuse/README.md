# Ordinary cache is the control to beat

`python3 -B -m bench.jev.angle_lab.reuse.run` compares full recomputation and an ordinary exact-request cache over1k/10k occurrences and five fixed mutations. Every occurrence output array must match an independently computed reference. Source, question, schema, model, contract and repository changes invalidate raw identity. Threshold changes derive new booleans from retained probabilities. Transient failures and unjudged results are not cached as semantic judgments.

A deliberately incomplete key produces an actually wrong result when the question changes. Duplicate content is deduplicated only within authorized scope and expanded back to every occurrence. Output bytes, lookup work, oracle evaluations and local wall time are counted separately.

The oracle is injected and deterministic. Its speed is NOT Jev speed; evaluations are NOT HTTP requests. No separate incremental optimizer is implemented and no superiority over ordinary memoization is claimed. New provider calls are unnecessary for this mechanism test. Real lane receipts separately describe model costs.
