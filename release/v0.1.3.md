# Azdaja v0.1.3

Azdaja v0.1.3 makes the public installer user-controlled and concise.

## Highlights

- Bare `curl -fsSL https://azdaja.dev/install | sh` detects supported harnesses and opens an interactive multi-select instead of installing every detected integration.
- `--all` remains available for explicit unattended installation.
- Comma-separated subsets such as `jcode,codex` are validated and installed in one atomic Rust transaction.
- Installer output is reduced to the installed version, selected integrations, and one doctor command.
- Existing checksum, platform, ownership, rollback, alias-collision, and provider-free guarantees remain enforced.

## Supported standalone binaries

- Apple Silicon macOS 11+
- x86-64 Linux with glibc 2.35+
