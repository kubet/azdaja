# Azdaja v0.1.2

Azdaja v0.1.2 strengthens the managed integration and large-input execution path across Jcode, Claude, Codex, Gemini, and OpenCode.

## Highlights

- Adds native Codex skill installation and improves Claude and OpenCode activation, routing, lifecycle, and answer handoff.
- Adds exact five-field nested model usage tracing for input, cache read, cache write, output, and reasoning tokens.
- Tightens owner-only state, process, installer, configuration, uninstall, and managed-file custody.
- Scales deterministic projection and compact semantic batching while bounding model-call count, workers, retries, and wall time.
- Co-distributes reviewed third-party notices and verifies release assets through `SHA256SUMS`.
- Adds a frozen same-model GPT-5.6 Luna diagnostic. On one synthetic 1.3 MiB task, Azdaja matched the exact native answer with 66.7% fewer uncached tokens and 54.8% less wall time on Codex, and 88.0% fewer uncached tokens and 63.7% less wall time on OpenCode.

The delta is a single candidate-only follow-up against hash-bound native rows. It is not a repeated, concurrent, or general-superiority benchmark. Exact plans, usage accounting, failed precursors, and the final receipt are retained under `bench/delta/`.

## Supported standalone binaries

- Apple Silicon macOS 11 or newer
- x86-64 Linux with glibc 2.35 or newer

Other platforms can use the locked Rust 1.95 source install.

Installation and validation remain provider-free. A model is contacted only when the user explicitly runs model-backed Azdaja work.
