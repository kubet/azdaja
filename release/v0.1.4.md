# Azdaja v0.1.4

Azdaja v0.1.4 adds polished local observability and finishes the interactive installer experience.

## Highlights

- Bare interactive `azdaja` now renders a fast, provider-free terminal dashboard with the configured model route, reasoning level, session capacity, active work, local state size, recent sessions, and command shortcuts.
- Dashboard data comes only from validated local configuration and owner-only session files. It never contacts a model provider.
- The curl installer now presents a real arrow-key checkbox selector with Space to toggle and Enter to install.
- All five integrations are always visible. Detected tools are highlighted in green, while the selected subset is still committed as one atomic Rust transaction.
- Non-terminal bare invocation keeps the stable five-line help output for scripts.

## Supported standalone binaries

- Apple Silicon macOS 11+
- x86-64 Linux with glibc 2.35+
