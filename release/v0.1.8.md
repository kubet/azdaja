# Azdaja v0.1.8

Azdaja v0.1.8 makes the provider-free console truthful about configuration, live sessions, and local source measurements.

## Console redesign

- A bare interactive `azdaja` prints a static provider-free snapshot. `az map` remains the optional full-screen view.
- `new work` now clearly identifies this invocation's configured default model, runner, and thinking level rather than implying an observed universal route.
- Every live session shows the default model persisted when that session was created. Concurrent sessions can therefore truthfully display different models, while individual model calls may still override a session default.
- Live sessions and local numeric source summaries are presented as separate kinds of state in the snapshot and in `az list`.
- The source-summary constellation has labeled source-size bands and a plain `repeated ← source variety → varied` axis. Each point represents one local numeric source summary.
- The overview reports `avg variety` from local aggregate numbers only. Exact Shannon byte entropy remains available in measured details on demand, with explicit distribution-only caveats.
- Source-summary privacy claims are scoped to the durable numeric summaries, which exclude source text, paths, hashes, prompts, and responses.

## Upgrade safety inherited from v0.1.7

- Byte-exact v0.1.5 managed Jcode and Codex configs migrate from `gpt-5.6-luna` to `gpt-5.6-sol`.
- Byte-exact v0.1.5 managed OpenCode configs migrate from `openai/gpt-5.6-luna` to `openai/gpt-5.6-sol`.
- The adjacent standalone config follows the same harness-qualified Luna-to-Sol migration.
- Customized or one-byte-different configs remain untouched, with the existing ownership, preflight, atomic rename, rollback, and provider-free guarantees.

## Supported standalone binaries

- Apple Silicon macOS 11+
- x86-64 Linux with glibc 2.35+
