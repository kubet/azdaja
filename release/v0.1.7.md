# Azdaja v0.1.7

Azdaja v0.1.7 is a focused upgrade-safety patch for the v0.1.6 memory constellation release.

## Fixes

- Byte-exact v0.1.5 managed Jcode configs now migrate from `gpt-5.6-luna` to `gpt-5.6-sol`.
- Byte-exact v0.1.5 managed Codex configs now migrate from `gpt-5.6-luna` to `gpt-5.6-sol`.
- Byte-exact v0.1.5 managed OpenCode configs now migrate from `openai/gpt-5.6-luna` to `openai/gpt-5.6-sol`.
- The adjacent standalone config follows the same harness-qualified migration, so `az` and the installed integration report the same route after upgrade.
- Customized or one-byte-different configs remain untouched.
- Migration retains the existing ownership, single-link, preflight, atomic rename, rollback, and provider-free guarantees.

## Included from v0.1.6

- Compact inline memory constellation with exact-local `H₀`, redundancy, line density, and retained aggregate memories.
- Details-on-demand through `az list` and the optional full-screen `az map` console.
- Durable aggregate-only completion memory with no source text, paths, prompts, responses, hashes, semantic labels, or session identifiers.

## Supported standalone binaries

- Apple Silicon macOS 11+
- x86-64 Linux with glibc 2.35+
