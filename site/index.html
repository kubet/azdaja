Aždaja (roughly azh-DAH-yah) is the many-headed Serbian dragon: one persistent body, parallel model-call heads, and an appetite for contexts too large for one window.

One binary, for any agent that can run a command. It loads a file into a persistent Python session; the model sees only metadata, writes code to read and question it, and calls sub-models in parallel from inside the sandbox. No chunking, no retrieval, no index — the strategy belongs to the model.

Point it at the hundred-megabyte log, the whole codebase, the transcript that never fit. It reads what it needs, fans out heads where it must, and comes back with one answer.
