# Visibility operations policy

This path is a policy and verification receipt, not an execution runbook. It intentionally contains no reusable Hacker News title, comment, or reply wording; no outreach targets, owners, statuses, schedules, timing, or contact routes; and no operator launch or promotion tactics.

Hacker News wording must be independently written and proofread by a human. Agents may verify public URLs and external factual state only. No content here authorizes posting, replying, emailing, submitting forms, requesting votes, or running paid inference.

## Factual verification boundary

Use only the product contract, immutable release notes, public URLs, and existing accepted receipts as evidence. Do not turn verification into a draft, queue, target list, or contact plan. Historical exposure cannot be erased, but it is not reproduced by this file.
