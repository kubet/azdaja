## Failure history and the exact acceptance boundary

1. Clean source `6ace261` failed the exact package-list test because `credentials.rs` was listed out of Cargo's canonical order. Membership was correct. Commit `64049c9` repaired only test/CI order. Current proof inventory was then rebound without modifying frozen evidence.
2. Clean source `e75d836` passed 17 prerequisite checks, then its full-suite command was killed at the outer 600-second limit while the final slow installer matrix was still running. That interrupted receipt is preserved, not rewritten as success. There were no reported failed tests before interruption.
3. The continuation verified all 17 completed log hashes at the unchanged clean source, then reran the **entire** full Rust suite and remaining installed workflows with a longer deadline. It did not resume halfway through an individual test or repeat a provider request.

The full rerun passed 669/0/5, the private installed native/pack/continuation suite passed 27 tests, the native/result suite passed 30 tests, and installed memory passed 2 tests. The explicit credential supplement covered fresh-process persistence, replacement, source priority, four zero-transport native paths, detach and uninstall. Its first harness attempt expected refusal exit 1, while the correct CLI returned 2. That harness expectation was fixed, its failed receipt and cleanup were preserved, and all 23 commands then passed against the same accepted binary.

The five full-suite exclusions were not erased: two installed-memory cases were run separately, while the three remaining stress/release-preparation exclusions are outside this local acceptance. Public notices, all 49 bound proof artifacts plus 12 verifier tests, source packaging, strict lint and formatting all passed. The complete new ingestion/RAG pipeline requested at 11:26Z is a **separate active study**, not retroactively covered by these results.

## Decision

The optional integration is useful infrastructure, not proof of a superior agent. The evidence supports pursuing **scoped evidence retrieval followed by explicit recovery of missing decisions** on a new, independently labeled panel. It does not justify automatic memory population, mandatory Jev gating, a dependency-graph engine, SOTA reranking, infinite attention, or a claimed RLM moat.

The next experiment and strong-control requirements are specified in the [results](jev-six-angle-results-20260917.md#executable-next-step-not-another-claim). Those are future work, not already passed requirements. Full distributed/team-product readiness remains false even when local engineering acceptance passes.
