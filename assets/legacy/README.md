# Historical managed configs

These files are byte-for-byte `config.toml` outputs from provider-free, isolated
`azdaja install <integration>` runs. They are migration custody fixtures. Do not
regenerate them from current defaults or normalize their formatting. Azdaja only
migrates an installed config when every byte matches one of these fixtures.
Customized or one-byte-different configs remain untouched.
