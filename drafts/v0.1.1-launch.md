# Draft — Azdaja v0.1.1: a bounded-context path for 50 MiB files

> **NONPUBLISHED DRAFT.** Do not post, merge into a release page, or treat this
> copy as a publication decision. Recheck anonymous repository, installer, tag,
> asset, and support availability immediately before any separately authorized
> publication. This draft makes no adoption claim.

Azdaja v0.1.1 packages one CLI for two exact binary platform pairs: Apple
Silicon macOS (`Darwin-arm64`) and Linux x86_64 (`Linux-x86_64`). Its product
contract is intentionally narrower than “put every byte in a model prompt”:
keep the full UTF-8 input in a persistent local evaluator, ask a model for
bounded analysis code, and send only explicitly selected context to semantic
calls.

## Proposed one-command publication copy

The repository is private. The command below is retained only as reviewed launch
copy; it is **not currently an anonymous install path** and must not be published
or used as an availability claim. Authenticated owners should use the source
install in the README until a separate visibility and anonymous-reachability GO.

```bash
curl -fsSL https://raw.githubusercontent.com/kubet/azdaja/v0.1.1/site/install | sh
```

When anonymously reachable under a separately authorized publication, the
versioned installer selects only `Darwin-arm64` or `Linux-x86_64`, verifies
the platform-bound SHA-256 digest, checks the local evaluator capabilities, and
installs the managed harness skill. Unsupported platform pairs fail before a
binary download. Other platforms require the documented Rust 1.95 source path.

Installation is **provider-free**: it does not call a model or prove that a
harness login works. Authentication is a separate, explicit action:

```bash
AZ="$HOME/.jcode/skills/azdaja/azdaja"
"$AZ" doctor
```

A successful `doctor` is a dial-tone check for the configured Jcode subscription
route, not an accuracy, reliability, or privacy certification.

## The exact 50 MiB gate

The installed v0.1.1 binary was exercised on both supported platform paths with
three synthetic UTF-8 inputs, each exactly **52,428,800 bytes**
(`50 × 1024 × 1024`): a build log, repository dump, and operational transcript.
All three cases on each platform returned their exact expected answer. The gate
also required a root prompt below **65,536 bytes**, no supplied host path or
exact 100-byte source span in the captured provider prompt, zero child calls,
and no retained session.

This is an offline scripted product-path acceptance test. The scripted harness
provides no expected answer, but it is still not evidence of general live-model
planning quality, arbitrary-file accuracy, an information-flow boundary, or a
memory ceiling. The native harness retains the user's host permissions, and
model-authored evaluator code can select source material for a model call.

## Why bounded context is the product story

Azdaja avoids automatically copying the entire file into the root request. For
the exact synthetic 50 MiB cases above, the observed root-prompt bound was less
than 64 KiB. That is useful as a context-shape guarantee for those cases—not as
a percentage token or money saving.

The [reproducible crossover figure](../docs/token-context-crossover.svg) is only
an illustration. It assumes four UTF-8 bytes per token for both lines and an
assumed constant 64 KiB root envelope; under those assumptions, a hypothetical
whole-input prompt reaches that envelope at 64 KiB of input. Exact product
evidence exists only at the three 50 MiB points. The figure omits child calls,
repairs, output tokens, caching, tokenizer differences, and provider pricing,
so it cannot establish total usage or savings.

Regenerate or check it with:

```bash
python3 tools/render_token_crossover.py
python3 tools/render_token_crossover.py --check
```

## Limitations

- The two prebuilt pairs are exactly Apple Silicon macOS and Linux x86_64;
  other systems are source-only.
- Product use requires a supported logged-in harness even though installation
  is provider-free.
- Keeping the full file in the evaluator does not make Azdaja an
  information-flow-control system. Selected context can still be sent to a
  provider.
- Root, child, repair, output, and cache behavior vary by task. No cost or token
  reduction is promised.
- Monty 0.0.21 is experimental and snapshot-format-bound; snapshots are
  unencrypted owner-only files, and there is no evaluator memory ceiling.
- The 50 MiB gate covers three synthetic cases. It does not establish accuracy
  or reliability for arbitrary workloads.
- Benchmark results are private diagnostics with stated evidence boundaries,
  not release acceptance, an official score, or evidence of adoption.

For a report, use only synthetic or sanitized reproduction material. Never post
raw inputs, traces, configuration, host paths, OAuth material, tokens, or
secrets. Security vulnerabilities belong in a private advisory.
